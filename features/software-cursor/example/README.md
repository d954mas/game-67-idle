# Sample Themes

`assets/` contains unchanged CC0 files for the two optional themes. The feature
returns symbolic ids; the consumer maps them to its own packed regions:

| Visual id | Suggested file |
|---|---|
| `SOFTWARE_CURSOR_SAMPLE_POINTER_IDLE` | `kenney_pointer_c_shaded_cc0.png` |
| `SOFTWARE_CURSOR_SAMPLE_POINTER_PRESS` | same pointer; press squash is runtime animation |
| `SOFTWARE_CURSOR_SAMPLE_FINGER_OPEN` | `touch_hand_open.png` |
| `SOFTWARE_CURSOR_SAMPLE_FINGER_PRESS` | `touch_hand_closed.png` |

A consumer may intentionally override the finger samples with its own
project-owned polished atlas regions.
