# ui-kit icon set

White glyph masks on a transparent background, tinted at runtime, so one set
serves every theme. A game packs the files it wants under one prefix and binds
them by name (`ui_theme_art_bind_icons`); a game that draws its own replaces
any file here with a same-named mask of its own.

## License

CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/), no attribution
required. Every file is a Kenney glyph re-encoded without pixel changes.

## Source-first search

1. Shared asset library: no icon pack.
2. Kenney CC0: `game-icons` (105 glyphs) covers the set except `coin`, which
   comes from `game-icons-expansion`. Both ship `PNG/White/2x` at 100x100, a
   flat white silhouette with anti-aliased alpha.
3. Generation: not needed.
