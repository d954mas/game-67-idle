# D2R Mobile — мобильное управление

Источник: [jhaizhou-ops/d2r-mobile](https://github.com/jhaizhou-ops/d2r-mobile), автор jhaizhou.
Проверено: 2026-10-13. Полученная ревизия: `00918bdd0089666ed1cdb6785c341b2e3489582d`.

Назначение: сохранить кросс-проектный референс сенсорного управления для RPG.
Фокус — навыки, выбор цели, подход к объектам и инвентарь. Дополнительные режимы
игры не являются предметом этой заметки.

Объем исследования: чтение документации и отдельных исходников. Это карточка
источника, не завершенная деконструкция управления и не готовая спецификация.
Игра не запускалась; видеозаписи и реальные ощущения от управления не проверены.

## Наблюдения

- `observed` — README описывает виртуальный стик, нажатие кнопки навыка для
  применения, удержание для повторения и перетаскивание для прицеливания.
  Также заявлены автоматический выбор ближайших монстров и два набора навыков.
- `observed` — README описывает жесты инвентаря: двойное нажатие для экипировки
  и снятия предмета, перетаскивание на панель торговца для продажи, долгое
  нажатие на пустую ячейку для сортировки.
- `observed` — раздел Controller заявляет переключение на интерфейс геймпада
  при нажатии его кнопки и возврат к сенсорному интерфейсу при касании экрана.
- `observed` — в `dm_world.c` взаимодействие с выбранным объектом использует
  функции оригинальной игры. Для подхода предусмотрены отмена ручным вводом,
  исчезновение цели, смена цели и тайм-аут; учитывается движение NPC.
- `observed` — в `dm_world.c` есть собственное планирование пути по сетке
  столкновений игры: поиск в ширину и упрощение маршрута до прямых отрезков.
  Выполнение движения остается за оригинальной программой.
- `observed` — есть расхождение источников: README заявляет перемещение
  нажатием на землю, тогда как начальный комментарий `dm_world.c` описывает
  подход к выбранному объекту и отсутствие перемещения от прочих касаний.
  `unknown` — фактическое поведение нажатия на пустую землю без запуска не установлено.

## Границы использования

- `observed` — это слой запуска Switch-версии Diablo II: Resurrected на iOS,
  а не открытые исходники самой Diablo. Оригинальную программу и ресурсы
  пользователь предоставляет отдельно.
- `observed` — дополнения вызывают внутренние функции игры по адресам.
  DERIVED описывает около 800 адресов в 59 файлах для версии 3.3.94012.
- `inferred` — полезнее изучать поведение управления и отдельно реализовывать
  его через API выбранного движка. Прямой перенос потребует отделения от
  структур памяти, команд и функций Diablo.
- `observed` — основной код опубликован под MIT с требованием сохранять
  уведомление об авторстве и лицензию. Зависимости имеют собственные условия;
  лицензия семи сторонних патчей офлайн-запуска указана как неизвестная.
  Графика, звуки, названия и прочий контент Diablo не становятся свободными
  ресурсами вследствие публикации этого репозитория.

## Что изучать при дальнейшем использовании

- `inferred` — кандидаты для заимствования поведения: сочетание нажатия,
  удержания и прицеливания; подход к интерактивной цели; явная отмена
  автоматического движения; жесты инвентаря; смена способа ввода.
- `unknown` — размеры зон касания, пороги распознавания жестов, перекрытие
  обзора пальцами, случайные продажи, выбор цели в толпе и удобство долгих сессий.
- Перед реализацией первичного управления нужна деконструкция по
  [Reference Deconstruction](../knowledge/reference_deconstruction.md):
  запись боя с прицеливанием, подхода к NPC за препятствием, отмены движения,
  переноса и продажи предметов, переключения геймпада и касаний; затем
  сравнение с прототипом целевой игры на устройстве.
