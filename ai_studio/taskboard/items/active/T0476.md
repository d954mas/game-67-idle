## What

`feature_workspaces.mjs remove` refused 13 of 15 merged, clean workspaces: a Studio worktree advanced to a newer master commit ("commit ownership mismatch"), generated `__pycache__`/`src/generated`/`release/artifacts` counted as unknown data, and Windows long paths broke `git worktree remove`. Workspaces therefore piled up (28 GB) and the registry lists 68 entries for 5 folders.

## Done when

- [ ] A Studio worktree whose HEAD is reachable from the source Studio branch is accepted; a commit only in the workspace still refuses.
- [ ] Generated ignored data (`__pycache__`, `src/generated`, `release/artifacts`, build outputs) is removed, not refused; evidence and restricted assets still refuse unless identical copies exist in the source game.
- [ ] Removal works with Windows paths over 260 characters.
- [ ] A command lists merged workspaces and removes them after a dry run, and another retires registry entries whose folders are gone.
- [ ] Tests cover each case.
