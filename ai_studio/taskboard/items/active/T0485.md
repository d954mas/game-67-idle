## What

Invert the hardwired room stack one slice at a time: room shell (lifecycle, seats, reconnect window, input queue) -> replication descriptor registry -> event op-code registry with a reserved control range -> relevance callback instead of hardwired districts. Schema hash derives from the registered descriptors.
