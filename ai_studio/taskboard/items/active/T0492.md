## What

`node tools/game.mjs test --only <name>` rebuilds only the test target. A test that receives another binary's path through its ENVIRONMENT property (a server, a tool) then runs a stale build of that binary and passes or fails against old code.

## Done when

- [ ] `--only` also builds every target a selected test names in its ENVIRONMENT, or the test declares that dependency in CMake.
- [ ] A changed server binary is rebuilt by `--only` of a test that runs it (shown by one run).
