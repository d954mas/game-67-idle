## What

The room server image build context comes from the Studio root, and its dockerignore admits `games/private/*/src`, `state`, `content` and tools for every private game. A game's room image build therefore copies other games' sources into the build context (and any layer that copies broadly).

## Done when

- [ ] A game's room image context admits only that game's directory plus the engine and features it builds.
- [ ] Both online games' room images build and run a netbench after the change.
- [ ] Image contents checked: no other game's sources.
