## What

Each feature workspace costs 1.3-2.1 GB: about 0.5 GB for a fresh Python `.venv` most tasks never use and about 0.8 GB rebuilding the engine and game from scratch.

## Done when

- [ ] `new` skips the Python environment unless asked; `prepare-python` creates it later.
- [ ] Engine build output is shared per engine revision and preset (or by a compiler cache) instead of rebuilt per workspace.
- [ ] A new workspace is measured before and after; the numbers are logged here.
