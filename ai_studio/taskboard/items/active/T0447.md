## What

Две мелочи, которые мешают всей остальной цепочке (T0448-T0450 и игровые карточки потребителя).
Ни от чего не зависят, делаются сразу.

**1. `features/validate_contracts.mjs` красный на чистом мастере.**

```
feature contracts invalid: localization feature contract: README router is missing '## Purpose'
```

В `features/localization/README.md` нет заголовка `## Purpose`. Пока он
красный, его нельзя ставить в приёмку остальных карточек — а он там нужен,
потому что дальше правятся контракты двух фич.

**2. `src/generated/items_catalog.gen.{h,c}` у приватного потребителя — мёртвый.**

Сгенерирован из каталога **шаблона** (6 предметов), не упомянут ни в одном
CMake этой игры. Живой дубль чужого каталога в чужом репозитории — ровно тот класс
болезни, который лечит вся цепочка. Не путать с целью `items_catalog_gen`
(`cmake/GameCodegen.cmake:52`) — она собирает блоб и к этим файлам отношения
не имеет.
