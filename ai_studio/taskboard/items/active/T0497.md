## What

A one-file web edit costs ~17 s: the default build is wasm-release with an -O3 link (8 s vs 1.4 s debug), and the web build wrapper reconfigures, hashes the tree twice and recopies the 18 MB site every run (no-op 8.4 s).

## Done when

- [ ] Day-to-day web build/run use a debug/devapi preset; release stays for package and portal work.
- [ ] No-op web build under 3 s; configure and tree hash run only when inputs changed.
- [ ] One-file web edit to runnable page measured before/after.
