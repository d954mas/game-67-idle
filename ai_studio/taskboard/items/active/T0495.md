## What

Studio verification runs all ten domains inside one job per OS, so they share four cores; Windows takes ~13 min (workspace domain alone ~466 s), Linux ~6 min. Stale runs keep running beside new ones, and a red step hides later checks so failures surface one CI round at a time.

## Done when

- [ ] Workflow cancels an older in-progress run for the same ref.
- [ ] Linux runs each domain (or domain group) as its own job; every domain's failures show in one run.
- [ ] Windows runs the domains that catch path and process issues (workspace, runtime, game tools), split so no job exceeds ~6 min.
- [ ] Wall time from push to the last result measured before and after.
