## What

About seven games (the online games, the RPG, the tram game and older ones) each keep a shader_programs.c of the same shape: one linked program per material pair, shared across materials, built and destroyed with the renderer. The engine's nt_program_ref covers a single program pair only. One small pack replaces the copies in the live games; frozen games keep theirs until unfrozen.

## Done when

- [ ] A features/ pack owns the program cache with tests in the Studio consumer.
- [ ] The live games use it and their own copies are gone; each game builds, tests pass, one screenshot per game shows the scene renders.
- [ ] live_games.mjs passes.
