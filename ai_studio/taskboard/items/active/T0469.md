## What

Games compile `features/` from Studio HEAD via `GAME_REPO_ROOT`, so `dependencies.json` versions are records, not pins. Five games record ui-kit 1.7 while current is 3.1; twelve record engine lock `"0.1.0"`, which `new_game --from` rejects.

## Done when

- [ ] A check fails when a game's recorded feature version differs from the feature's `feature.json`, or the engine lock is not a revision.
- [ ] The four live games pass it.
- [ ] Frozen games (T0465) are exempt.
