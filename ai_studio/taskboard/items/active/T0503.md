## What

The two online games carry byte-identical generic code that is not game-flavoured: cascaded shadow maps, frustum culling and post-processing in the renderer, number formatting and UI theme helpers, and the room server host shell (process sampling, server.c differing by 3 lines). Lead decision: only very generic pieces move to features/; game-flavoured code stays per game and the newer game drops copies it does not use (T0502).

## Done when

- [ ] Research lists each identical piece with a verdict (generic -> feature, game-flavoured -> stays) reviewed by a subagent and Codex.
- [ ] Each generic piece lives once under features/ (new or existing pack) with its own test; both games use it and their copies are deleted.
- [ ] Both games build, run their core tests and render as before (screenshot for render changes); live_games.mjs passes.
