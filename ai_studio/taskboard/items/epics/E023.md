## Goal

Make the four live games (two multiplayer simulators, two single-player games) iterate faster: shorter edit-test loops, less manual fan-out, fewer repeated design regressions.

## In scope

- Quick wins in test speed, transcript volume, taskboard noise and quality-gate ritual.
- Freezing the ten inactive games so Studio changes stop fanning out to them.
- Honest feature versions, a shared game CLI core, skill surface fixes.
- Ideas for design invariants, a shared multiplayer simulator stack, universal layout, pre-moderation checks.

## Out of scope

- New templates or genre kits (no new game planned).
- Engine changes (engine repo issues/PRs only).
- Reviving frozen games.
